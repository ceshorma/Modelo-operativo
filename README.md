# Modelo operativo · IA & Data

Repositorio paraguas para las presentaciones interactivas del modelo operativo de IA & Data.

## Módulos

- `people/` — Pilar operativo de Personas: visibilidad, People Lead, Talent, staffing, capacidades y plan de 90 días.
- `applied-ai/` — IA aplicada & Analytics: foco y oferta, desarrollo de mercado, excelencia técnica y de entrega, innovación y conocimiento reutilizable. Presentación de 14 escenas con un piloto propuesto de 90 días.

Las presentaciones están construidas como HTML estático autocontenido para poder publicarlas mediante GitHub Pages. Incluyen navegación por clic; el módulo de IA aplicada & Analytics también permite abrir el índice y el guion desde la barra superior.

## Publicación

El repositorio incluye un workflow de GitHub Actions para desplegar automáticamente la rama `main` en GitHub Pages.

- [Portada del modelo operativo](https://ceshorma.github.io/Modelo-operativo/)
- [Pilar de Personas](https://ceshorma.github.io/Modelo-operativo/people/)
- [IA aplicada & Analytics](https://ceshorma.github.io/Modelo-operativo/applied-ai/)

## Alcance

Las presentaciones describen modelos de trabajo propuestos, no políticas oficiales ni resultados actuales. Las metas del piloto deben contrastarse con la línea base y la capacidad del equipo. Las notas del presentador forman parte del HTML público.
